OpenStreetMap Civic Amenities: Istanbul, Cairo, Mumbai

359 features, 3 cities3 amenity types2026-09-10 countedfree CSV

One CSV, nine rows: Istanbul, Cairo, and Mumbai × three civic amenity types. Each row is the count of OpenStreetMap features carrying that amenity tag inside the city's administrative boundary, queried from the Overpass API in one run, with the license line carried verbatim in a fourth column.

The amenity tags are amenity=drinking_water (fountains and public tap points), amenity=public_bookcase (street-side book-sharing shelves), and amenity=bicycle_repair_station (public stands with tools or an air pump). The query shape is area(id)->.a; nwr["amenity"="drinking_water"](area.a); out count;, one call per theme per city, area-filtered rather than bbox-filtered, so the numbers follow exact city limits.

Istanbul owns this comparison: 194 mapped drinking-water features, most of them historic Ottoman street fountains (çeşme) recorded with mappers' names and dates, plus 16 bike repair stands. Mumbai counters with 67 fountains including a run of pyau drinking-water stations and 3 cycle repair shops. Cairo has 78 water points and zero bookcases or repair stands mapped anywhere in the governorate — nobody has gotten to it yet, not an absence of either thing on the ground.

Counts ran on 2026-09-10 against the Overpass API (kumi.systems mirror, keyless), so the numbers are a snapshot of a database that moves daily. Boundaries are Nominatim administrative relations (Istanbul R223474 for the province, Cairo R5466227 for the governorate, Mumbai via its two district relations R7964375 + R7964376 because the city relation carries no Overpass area), each passed to Overpass as its 3600000000-offset area ID.

For the same three amenity types elsewhere in the catalog, see the OSM US civic amenities dataset (New York, Los Angeles, Chicago, Austin, Seattle), the OSM Asia civic amenities dataset (Tokyo, Jakarta, Seoul), the OSM EU civic amenities dataset (Berlin, Amsterdam, Paris, Madrid, Warsaw), and the OSM Latin America civic amenities dataset (São Paulo, Buenos Aires, Mexico City), plus the OSM Africa civic amenities dataset (Lagos, Nairobi, Addis Ababa).
