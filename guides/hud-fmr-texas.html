HUD FMR Texas: fair market rent data for Texas, FY2026

FY2026 edition, published 2026-09-10. Data source: HUD, public domain. Data Vault is not affiliated with HUD. This page documents the data; it is not housing or legal advice.

Texas in the FY2026 FMR files

Texas is the second-largest state in the HUD FMR FY2026 pack by row count. Filtering the ZIP file on state = TX matches 3,247 of the 51,895 rows, about 6 percent of the file. The county file adds 254 Texas county rows, and the 52-row state summary carries one Texas row. Together the three files give you the state at three levels: ZIP, county, and one-line summary.

Inside the ZIP file, the 3,247 Texas rows break down into 215 distinct HUD areas. 47 of them are metro FMR areas, where HUD publishes ZIP-level Small Area FMRs, and the other 168 are nonmetro counties that carry a county-level value. That split shows up in the values. Metro ZIPs vary within a metro, and nonmetro ZIPs repeat their county number.

Query the file for Texas

Filtering on the state column is the fastest way in. In a spreadsheet, filter the state column for TX. For scripts and agents, the dataset-mcp server takes a where clause, setup on the For agents page. This query runs against the full ZIP file:

query_dataset(
  "hud-fmr-2026",
  {
    "where": [{ "column": "state", "op": "=", "value": "TX" }],
    "columns": ["zip", "area_name", "fmr_2br"],
    "limit": 5
  }
)

Texas at a glance, from the state summary row

The state summary file condenses Texas to one row. In FY2026 the state-wide 2BR median across Texas ZIPs is 1,190, the cheapest ZIP values out at 970, and the priciest ZIP reaches 2,900. The summary also names the extremes at the county level: Rockwall County holds the highest 2BR in the state at 1,931, and Bailey County the lowest at 973. The full 52-row file, Texas included, is available as a free CSV download, so you can put Texas next to the other 51 states without paying anything.

HUD FMR Texas questions

How many Texas rows are in the HUD FMR data?
The FY2026 ZIP file holds 3,247 Texas rows out of 51,895 total, one row per Texas ZIP code. The county file adds 254 Texas county rows, and the 52-row state summary carries one Texas row with the state-wide median, the highest county, and the lowest county.
Why do Dallas and Fort Worth carry different FMRs if they are one metroplex?
HUD splits the Dallas-Fort Worth metroplex into separate HUD Metro FMR Areas. In FY2026 the Dallas area covers 260 Texas ZIPs with 2BR FMRs from 1,030 to 2,900, while Fort Worth-Arlington covers 126 ZIPs with 2BR values from 970 to 2,800. Each ZIP takes the FMR of the HUD area it belongs to, so the two sides of the metroplex are priced apart in the file.
What is the cheapest and most expensive 2BR FMR in Texas for FY2026?
Texas ZIP-level 2BR FMRs run from 970 dollars at the low end to 2,900 at the high end. The state summary names Rockwall County as the highest-rent county at a 2BR of 1,931 and Bailey County as the lowest at 973. The state-wide median across the 3,247 Texas ZIP rows is 1,190.
