NFL scores dataset: where to download every score since 1999

Guide to the NFL Games & Betting Lines 1999-2026 pack · checked 2026-09-10 · loading the sample in code? The pandas quickstart runs three analyses on it · other leagues covered in the free sports data CSV guide

Three downloads cover the keyword "nfl scores dataset" from different angles:

  • nflverse games.csv is the full history: 7,548 data rows, one per game from 1999 through the current season, 46 columns including home_score and away_score, free under CC BY 4.0.
  • ESPN's scoreboard API answers without a key and returns the current week as JSON, 16 events when tested for week 1 of the 2026 season.
  • the free 22-row sample on this site is real game data, weeks 1 and 2 of the 1999 season, with all 46 columns and no signup.

The sections below walk each source, then run pandas on the sample to show what the score columns look like in practice.

nflverse games.csv: the full-history download

The nflverse-data project publishes games.csv in its nfldata repository, under data/games.csv. One row per game, 1999 through the current season: 7,548 data rows plus the header when checked on 2026-09-10, about 2.1 MB. The license is CC BY 4.0, so commercial use is fine with credit.

The header, verbatim, all 46 columns in file order:

game_id,season,game_type,week,gameday,weekday,gametime,away_team,
away_score,home_team,home_score,location,result,total,overtime,
old_game_id,gsis,nfl_detail_id,pfr,pff,espn,ftn,away_rest,home_rest,
away_moneyline,home_moneyline,spread_line,away_spread_odds,
home_spread_odds,total_line,under_odds,over_odds,div_game,roof,
surface,temp,wind,away_qb_id,home_qb_id,away_qb_name,home_qb_name,
away_coach,home_coach,referee,stadium_id,stadium

The score columns sit up front: away_score and home_score hold final points, result is the home margin already computed (home points minus away points), and total is the combined score. Scheduled games carry blank scores until they finish. The odds columns (spread_line, total_line, moneylines) are blank before 2006. Every column group is explained in the games.csv column guide.

One trade-off to know: the file is a rolling snapshot of the master branch, so the row count moves as new weeks are played, and historical corrections land silently. The nflverse vs preprocessed pack comparison covers what that means for reproducible work.

ESPN scoreboard API: this week's scores, no key

For the current week rather than history, ESPN serves the JSON its own scoreboard page renders, and the endpoint answers any client:

https://site.api.espn.com/apis/site/v2/sports/football/nfl/scoreboard

Tested on 2026-09-10: HTTP 200, 16 events, season week: 1 of 2026, first event "New England Patriots at Seattle Seahawks". No key, no signup. Two quirks from the same test: score arrives as a string, not a number, and the nesting is deep because the feed is built for ESPN's pages. The ESPN API in Python guide walks the response with requests and prints real scores from a finished week.

The free 22-row sample, real data from 1999

This site mirrors the schema as a free sample: sample.csv, 22 rows, all 46 columns, weeks 1 and 2 of the 1999 season (game dates 1999-09-12 through 1999-09-19). It is the first 22 rows of the pack's games.csv, which was downloaded from nflverse on 2026-09-06 with the SHA-256 recorded. Nothing about it is synthetic: real teams, real scores, blank temp and wind where the 6 dome games never recorded them.

Free alongside it: season-summaries.csv, a complete 27-row table with scoring averages and win rates for every season 1999-2025.

What the score columns say: margins and blowouts

Two real pandas runs against the sample URL, verbatim code and output. First, the distribution of winning margins:

import pandas as pd

games = pd.read_csv("https://jayjex.github.io/data-vault/data/nfl-games/sample.csv")
games["margin"] = (games["home_score"] - games["away_score"]).abs()

print(games["margin"].describe().round(1))
print((games["margin"] >= 17).sum(), "blowouts")
print((games["margin"] <= 8).sum(), "one-score games")

The median margin is 7 points and 13 of 22 games finished within one score, which is what a competitive league should look like. The max, 43, is the sample's one shutout.

Second, every game in the sample decided by 17 or more, sorted:

blowouts = games[(games["home_score"] - games["away_score"]).abs() >= 17].copy()
blowouts["margin"] = (blowouts["home_score"] - blowouts["away_score"]).abs()
blowouts = blowouts.sort_values("margin", ascending=False)
print(blowouts[["gameday", "away_team", "away_score",
                "home_team", "home_score"]].to_string(index=False))

The biggest is Cleveland's 1999 expansion debut, a 43-0 home loss to Pittsburgh. The wildest score line in the sample went the other way from its margin: Dallas 41, Washington 35 in overtime, 76 combined points, the sample's highest total (the lowest was 20, Jets 3 at Bills 17). Note that these runs used the URL directly in read_csv, no download step. Caveat that matters: 22 rows are a pandas exercise, not a trend. Every claim here is about these weeks, and the full file is what you analyze for real findings. The pandas quickstart shows the same discipline on win counts, dome scoring, and kickoff temperatures.

NFL scores dataset questions

Where can I download NFL scores as a CSV?
nflverse-data publishes games.csv as a direct download, one row per NFL game from 1999 through the current season, 7,548 data rows with home_score and away_score on every finished game, under CC BY 4.0. On this site, a free 22-row sample of the same file downloads with no signup, and the full pack adds the complete file with team records and season summaries.
How many columns does the nflverse games.csv have?
46 columns, read from the file header: game_id, season, game_type, week, gameday, weekday, gametime, away_team, away_score, home_team, home_score, location, result, total, overtime, old_game_id, gsis, nfl_detail_id, pfr, pff, espn, ftn, away_rest, home_rest, away_moneyline, home_moneyline, spread_line, away_spread_odds, home_spread_odds, total_line, under_odds, over_odds, div_game, roof, surface, temp, wind, away_qb_id, home_qb_id, away_qb_name, home_qb_name, away_coach, home_coach, referee, stadium_id, and stadium. The score columns are away_score and home_score, and the derived result and total columns give the margin and combined points directly.
Can I get NFL scores for free without an API key?
Yes. The nflverse games.csv is a plain file download with no account. ESPN's scoreboard endpoint at site.api.espn.com answers without a key and returns the current week as nested JSON, 16 events when tested for week 1 of the 2026 season. The dataset-mcp server on this site also queries the full 7,548-row NFL file for free, 100 rows per call, no key.
