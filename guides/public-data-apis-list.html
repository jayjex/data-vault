Public data APIs: 12 free endpoints tested live

Published 2026-09-10. Every endpoint below returned HTTP 200 in a curl run from our own box, and the sample output is pasted verbatim from that same run.

How this free public API list was built

Most public API lists read like they were written from memory. Ours came from a terminal: 18 candidate endpoints, one curl call each on the day this page went up, a fixed User-Agent string, and a hard rule that anything without a 200 gets cut. Twelve survived. Every sample below shows real output from that run, trimmed to one line so the shape of each response stays visible.

The tests measured three things per API: whether a key was required, whether the response carries rate-limit headers, and what the payload actually looks like. Rate-limit headers came back empty on all twelve, so each entry notes what the provider documents instead of a number we guessed at.

What got cut, and the exact wall each one hit

Failures are data too. These candidates returned something other than 200, so they stay off the list until they change:

  • College Scorecard (api.data.gov): 403 API_KEY_MISSING, signup wall in front of every query.
  • Census data endpoints (ACS, decennial): 200 status but a Missing Key HTML page, a key wall behind a 200.
  • FRED REST API: 400 Variable api_key is not set.
  • SEC EDGAR companyconcept: 403 despite a declared User-Agent.
  • CryptoCompare: 401 API key required.
  • Coinbase, Binance, Kraken, NASA api.data.gov: connection never completed from our test box.

FAQ

What are the best free public data APIs without a key?

All twelve APIs on this page returned live data with no key when we tested them: US Census discovery data, Treasury interest rates, BLS unemployment, USGS earthquakes, World Bank indicators, FRED series CSV, ESPN NFL scoreboard, MLB teams, TheSportsDB team search, Open-Meteo weather, National Weather Service points, and CoinGecko prices.

Do these public APIs require an API key?

None of the twelve test calls needed one. The Census data endpoints changed policy and now reject keyless data queries with a Missing Key page, but the discovery catalog at api.census.gov/data.json still answers without a key, and FRED's REST API needs a key while its fredgraph.csv series endpoint does not.

How do you test whether a public API still works?

Run one curl request per endpoint on the same day the list is published, record the HTTP status and the first bytes of the response, and drop anything that fails or hits a signup wall. This list started with 18 candidates; 12 passed and the rest are documented as excluded with the exact error each one returned.
