Public bookcase, drinking water fountain, and bike repair station maps: 19 cities worldwide

Most map apps treat street-level civic infrastructure as an afterthought. OpenStreetMap does not: contributors tag drinking fountains (amenity=drinking_water), public bookcases (amenity=public_bookcase), and bike repair stations (amenity=bicycle_repair_station) point by point. This guide counts those three tags across 19 cities in six regions — 13,783 nodes in total — and publishes the numbers as free CSV, so a public bookcase map worldwide, a drinking water fountain map, or a bike repair station map app can start from real coverage numbers instead of guesswork. The query-level walkthrough lives in the OSM civic data guide; this page stays at the worldwide view.

19 cities, six regions, 13,783 nodes

The set covers five US cities, five EU cities, three Asian cities, three Latin American cities, and three African cities. Every number is the count of OSM elements carrying that amenity tag inside the city on the snapshot date; the last column sums the three:

Where the counts cluster

Seattle owns the bookcase count: 497 of the 1,334 counted in this set, more than double second-place New York City's 221. That tracks with the Little Free Library movement running strongest in the US Pacific Northwest. Paris leads the EU at 165, while Amsterdam's 0, Jakarta's 1, and all nine Africa bookcase cells at 0 are mapping-culture gaps rather than empty streets; the public_bookcase tag never caught on there.

Fountains now concentrate in three capitals. Nairobi maps 2,174 drinking-water points, mostly unnamed taps with a dense Kibera cluster, the largest count in this table and the second-largest in the catalog's civic series; Sydney's 2,479 in the Oceania file (not part of this table) holds the catalog top spot. Tokyo follows at 2,163 and Madrid at 2,058; together they hold 54% of this table's 11,896 fountains, consistent with the public-fountain networks both cities maintain. Paris adds 1,045. Bike repair stations flip the pattern: Warsaw's 188 stands top every other city, and no second city crosses 100 (Berlin, 71).

LatAm counts run small across every theme — Buenos Aires 185 nodes, Sao Paulo 116, Mexico City 84 — and fountains carry 90% of the region's 385 nodes. Whether that reflects fewer amenities or thinner tagging is what a second snapshot would settle. Africa's 2,240 features ride almost entirely on Nairobi's water points; outside that column the region counts one repair stand and zero bookcases.

From counts to a worldwide map or an app

A per-city count answers the first question any map project should ask: is there enough content to map? Seattle's 497 bookcases give a public bookcase map real material; Amsterdam's 0 means the layer would start empty, and the fix is fieldwork, not code. The same check applies to a bike repair station map app, where Warsaw's 188 stands and Madrid's 3 sit at opposite ends, and to a drinking water fountain map, where even the smallest city in the set (Addis Ababa, 5 nodes across all three tags) has enough fountains to plot a walking route.

Counts also give a data pipeline or an LLM a stable table instead of rendered tiles: one row per city, fixed columns, no JavaScript to run. To go from counts to coordinates, query the Overpass API with the same three amenity tags inside one city area; the Asia counts file ships one example location per amenity with name, latitude, and longitude, which shows what a single row of that output looks like.

Method and snapshot date

All counts ran on 2026-09-10 against the Overpass API, so they are snapshots of a database that changes daily. The EU, Asia, and LatAm counts filter by administrative boundary, with Nominatim relation lookups (Madrid R5326784, Tokyo R1543125, Buenos Aires R3082668, and the rest) converted to Overpass area IDs, so the numbers follow exact city limits. The US counts filter by city bounding box, close enough for the five cities chosen because their boxes stay inside the city proper. The Africa counts resolve Lagos State (R3718182), Nairobi County (R3492709), and the Addis Ababa city administration (R1707699) to Overpass area IDs the same way. The Oceania set is not in this table: it counts a different trio (toilets and benches instead of bookcases and repair stands), 27,231 features covered in the OSM civic data guide. The latest region added to this table is covered in the Istanbul-Cairo-Mumbai guide, with 359 more features counted inside exact admin boundaries. The query syntax, relation IDs, and retry logic are documented in the OSM civic data guide.
