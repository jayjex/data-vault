ZIP prefix geography: what the first two digits of a ZIP code say about rent

Published 2026-09-10. Data source: the FY2027 fair market rent file by ZIP code, 51,871 rows, every number on this page computed from that file on 2026-09-10. Two-bedroom rents throughout, medians in dollars per month, no product prices involved. This page documents the data.

51,871 ZIP rows, 99 prefixes, 52 state pools8 states live entirely inside one prefix3,330 top prefix median, 10x Manhattan610 floor prefix median, 00x Puerto Rico4,110 widest within-prefix span, 95xxx

The short answer

Take the 51,871 ZIP rows in the FY2027 file and cut the ZIP code down to its first two characters, 76437 becomes 76. Ninety-nine of the hundred possible prefixes appear (09x is empty), and each collects the ZIPs that mail sorts through one sectional center facility. Across the file those 99 prefixes lean hard toward state lines: 42 contain exactly one state, 57 spill across at least one border, and 8 of the 52 state pools, Puerto Rico 00x, Vermont 05x, Massachusetts in 01x, New Hampshire 03x, Rhode Island 02x, Connecticut 06x, South Carolina 29x and Hawaii 96x, keep every one of their ZIPs inside a single prefix. Texas runs the other way, eight prefixes, and California spans nine, the most of any state.

Rent sorts along the same seams. The whole file medians 1,190 for a two-bedroom; the ten priciest prefixes run 2,210 to 3,330, and the cheapest, 00x, sits at 610. From Manhattan's 3,330 down to Puerto Rico's 610 is a 5.46-to-1 gap, and the widest spread inside a single prefix is 4,110, ZIP 95527 in Trinity County at 1,150 against ZIP 95060 in Santa Cruz at 5,260, both under 95x. Every board below recomputes from the one-row-per-prefix CSV, and the two SQL blocks at the end of this page return them verbatim.

Methodology: the file and what each number is

The source is the FY2027 fair market rent file by ZIP code: 51,871 rows, one per ZIP, with fields zip, hud_area_code, metro, area_name, state and five FMR columns for 0BR through 4BR, parsed from HUD's FY27 workbooks and shipped as a documented CSV (md5 c075a69de6c60ffd99ac6dba3a9b7899). Every number on this page uses the fmr_2br column. A prefix is the first two characters of the zip field, zero-padded; a state pool is all rows sharing a state column value, which gives 52 pools including DC and Puerto Rico; the file median is the middle value across all 51,871 rows, the average of the two middle rows for even counts, and the same convention applies to every prefix and state median here.

Grouping by prefix is an approximation of grouping by state, and the page measures that approximation rather than assuming it: 42 of 99 prefixes are single-state, 57 cross at least one state line, 8 state pools sit entirely inside one prefix, and prefix 09x holds no rows. Where a prefix spans states, its median mixes those states' markets by construction; the tables keep the state column visible wherever a row depends on it. The prefix CSV carries the 99-row aggregate: prefix, member states, ZIP count, median, min and max 2BR. Every board, median and spread on this page was computed three ways over the source file, a python pass, an independent SQLite pass, and the verbatim page SQL below, with zero mismatches.

Recompute the boards yourself

Load the source CSV into SQLite as zip2027, ten columns per row. The state board needs one ordering by row count:

-- SQLite: the ten largest state pools by ZIP rows
CREATE TABLE zip2027 (zip TEXT, hud_area_code TEXT, metro TEXT, area_name TEXT,
  state TEXT, fmr_0br INT, fmr_1br INT, fmr_2br INT, fmr_3br INT, fmr_4br INT);
.import --skip 1 fmr-by-zip-2027.csv zip2027

WITH c AS (SELECT state, COUNT(*) AS zips,
                  ROW_NUMBER() OVER (ORDER BY COUNT(*) DESC, state) AS rn
           FROM zip2027 GROUP BY state),
m AS (SELECT state, fmr_2br,
             ROW_NUMBER() OVER (PARTITION BY state ORDER BY fmr_2br, zip) AS r2,
             COUNT(*) OVER (PARTITION BY state) AS n
      FROM zip2027)
SELECT c.rn, c.state, c.zips, ROUND(c.zips * 100.0 / 51871.0, 1) AS share_pct,
  (SELECT ROUND(AVG(fmr_2br)) FROM m WHERE m.state = c.state
     AND r2 IN ((n+1)/2, (n+2)/2)) AS median_2br,
  (SELECT p FROM (SELECT state, SUBSTR(zip,1,2) AS p, COUNT(*) AS cz
                  FROM zip2027 GROUP BY state, p)
     WHERE state = c.state ORDER BY cz DESC, p LIMIT 1) AS top_prefix,
  (SELECT cz FROM (SELECT state, SUBSTR(zip,1,2) AS p, COUNT(*) AS cz
                   FROM zip2027 GROUP BY state, p)
     WHERE state = c.state ORDER BY cz DESC, p LIMIT 1) AS top_prefix_zips
FROM c ORDER BY rn LIMIT 10;

The prefix boards come out of the same table, one ordering by median and one by span:

-- SQLite: the ten most expensive prefixes by median 2BR, with floor and ceiling
WITH c AS (SELECT SUBSTR(zip,1,2) AS prefix, COUNT(*) AS zips,
                  MIN(fmr_2br) AS min_2br, MAX(fmr_2br) AS max_2br
           FROM zip2027 GROUP BY prefix),
m AS (SELECT SUBSTR(zip,1,2) AS prefix, fmr_2br,
             ROW_NUMBER() OVER (PARTITION BY SUBSTR(zip,1,2) ORDER BY fmr_2br, zip) AS r2,
             COUNT(*) OVER (PARTITION BY SUBSTR(zip,1,2)) AS n
      FROM zip2027),
med AS (SELECT prefix, ROUND(AVG(fmr_2br)) AS median_2br FROM m
        WHERE r2 IN ((n+1)/2, (n+2)/2) GROUP BY prefix)
SELECT ROW_NUMBER() OVER (ORDER BY med.median_2br DESC, c.prefix) AS rn,
  c.prefix, c.zips, med.median_2br, c.min_2br, c.max_2br
FROM c JOIN med ON med.prefix = c.prefix
ORDER BY rn LIMIT 10;

WITH c AS (SELECT SUBSTR(zip,1,2) AS prefix, COUNT(*) AS zips,
                  MIN(fmr_2br) AS min_2br, MAX(fmr_2br) AS max_2br,
                  ROW_NUMBER() OVER (ORDER BY MAX(fmr_2br) - MIN(fmr_2br) DESC) AS rn
           FROM zip2027 GROUP BY prefix),
h AS (SELECT SUBSTR(zip,1,2) AS prefix, zip, area_name, fmr_2br,
             ROW_NUMBER() OVER (PARTITION BY SUBSTR(zip,1,2) ORDER BY fmr_2br DESC, zip) AS r3
      FROM zip2027),
l AS (SELECT SUBSTR(zip,1,2) AS prefix, zip, area_name, fmr_2br,
             ROW_NUMBER() OVER (PARTITION BY SUBSTR(zip,1,2) ORDER BY fmr_2br, zip) AS r4
      FROM zip2027),
m AS (SELECT SUBSTR(zip,1,2) AS prefix, fmr_2br,
             ROW_NUMBER() OVER (PARTITION BY SUBSTR(zip,1,2) ORDER BY fmr_2br, zip) AS r2,
             COUNT(*) OVER (PARTITION BY SUBSTR(zip,1,2)) AS n
      FROM zip2027)
SELECT c.rn, c.prefix, c.zips,
  (SELECT ROUND(AVG(fmr_2br)) FROM m WHERE m.prefix = c.prefix
     AND r2 IN ((n+1)/2, (n+2)/2)) AS median_2br,
  c.min_2br, c.max_2br, c.max_2br - c.min_2br AS span,
  (SELECT zip || ' ' || area_name FROM h WHERE h.prefix = c.prefix AND r3 = 1) AS hi_zip,
  (SELECT zip || ' ' || area_name FROM l WHERE l.prefix = c.prefix AND r4 = 1) AS lo_zip
FROM c ORDER BY rn LIMIT 10;

SELECT (SELECT COUNT(*) FROM zip2027) AS zips,
  (SELECT COUNT(DISTINCT state) FROM zip2027) AS states,
  (SELECT COUNT(DISTINCT SUBSTR(zip,1,2)) FROM zip2027) AS prefixes,
  (SELECT ROUND(AVG(fmr_2br)) FROM (SELECT fmr_2br,
           ROW_NUMBER() OVER (ORDER BY fmr_2br, zip) AS r2,

Swap the board key to MAX(fmr_2br) - MIN(fmr_2br) on the 0BR column to see Puerto Rico's 00x hold the narrowest spread in the file instead, or point the medians at fmr_4br to watch Honolulu's 968xx climb toward the top.

ZIP prefix geography: questions

What do the first two digits of a ZIP code tell you?
They group ZIP codes into about a hundred routing zones, and in the FY2027 rent file each zone leans hard toward one state: 8 of the 52 state pools live entirely inside a single prefix, and 42 of the 99 prefixes used contain exactly one state. The mapping is not exact, 57 prefixes cross at least one state line, so the state column in any dataset stays the authority and the prefix works as a fast approximation.
Which ZIP prefix has the highest rents in FY2027?
Prefix 10x, Manhattan and the Hudson Valley counties, medians 3,330 for a two-bedroom, and prefix 11x, Long Island, follows at 2,910, so New York City owns the top of the board with two prefixes. California takes four of the ten most expensive prefixes: 94x at 3,270, 90x and 91x tied at 2,960, and 92x at 2,820. The cheapest is prefix 00x, Puerto Rico, at 610, a 5.46-to-1 gap between the two ends of the file.
How are the prefix medians computed?
Each ZIP code row contributes its two-bedroom fair market rent, the rows in a prefix are sorted, and the median is the middle value, the average of the two middle rows when a prefix holds an even count. The 95xxx prefix shows why a median matters there: it holds 677 ZIPs from Trinity County at 1,150 to Santa Cruz ZIP 95060 at 5,260, a 4,110 span, and its median of 1,930 describes neither endpoint.
