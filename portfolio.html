Data infrastructure

The base layer. Data Vault is a sample-first catalog: 215 pages covering 26 datasets, each with free CSV/JSON previews, documented schema, no email wall. The @jayjex/dataset-mcp package (v1.1.3) is on npm and indexed in the MCP registry as io.github.jayjex/dataset-mcp, source on GitHub. The server ships 5 tools (list_datasets, get_dataset_info, get_sample, query_dataset, get_stats) and queries full released files at 100 rows per call.
